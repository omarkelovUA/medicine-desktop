# 💊 Ліки родини

Настільний застосунок (JavaFX) для планування та контролю прийому ліків усією родиною на одному комп’ютері.

- Окрема вкладка для кожної особи, вкладка «Усі».
- Два види на кожній вкладці: **Картки** (дози на сьогодні) та **Шкала часу** (курси ліків на часовій осі).
- Курс ліків: визначена тривалість (дні / тижні / місяці / роки) або «Постійно».
- Частота: щодня, щотижня (обрані дні), щомісяця (обране число) — з одним або кількома часами прийому.
- Позначки «прийнято», прострочені дози червоним, пропущені — в історії.
- Історія прийому з відсотком дотримання для кожних ліків.
- Нагадування у вікні застосунку (поки він відкритий).
- Синхронізація з Google Календарем — для кожної особи у її власний акаунт.

## Шкала часу

Перемикач **Картки | Шкала часу** є на вкладці «Усі» та на вкладці кожної особи.

- Кожні ліки — окремий рядок; смуга кольору ліків тягнеться від початку до кінця курсу.
  Курс «Постійно» виходить за правий край зі стрілкою «→».
- Масштаб: **Дні · Тижні · Місяці · Квартали · Роки**; кнопки **‹ Сьогодні ›** гортають період.
- Червона вертикальна лінія — сьогодні. На вкладці «Усі» ліки згруповані за особами.
- Видно й завершені курси, якщо вони потрапляють у вибраний період.
- Наведіть на смугу, щоб побачити дати курсу; клік відкриває редагування ліків.
- Вибраний вид і масштаб запам’ятовуються.

## Вимоги

- JDK 21 або новіший
- Maven 3.9+

## Запуск

```bash
mvn javafx:run
```

Тести:

```bash
mvn test
```

## Встановлення в меню застосунків (Linux)

```bash
packaging/linux/install.sh
```

Скрипт збирає застосунок разом із власною Java (окремий JDK для запуску не потрібен) і встановлює його лише для поточного користувача:

| Шлях | Що це |
|---|---|
| `~/.local/opt/Medicine/` | застосунок |
| `~/.local/share/applications/ua.medicine.desktop` | пункт меню «Ліки родини» |
| `~/.local/share/icons/hicolor/…/ua.medicine.*` | іконка |

Після встановлення застосунок можна знайти в меню (клавіша Super → «Ліки») і закріпити на панелі.

**Оновлення.** Після змін у коді просто запустіть скрипт ще раз — він перезбере застосунок і замінить встановлену версію. Перед цим закрийте застосунок. Дані в `~/.medicine/` не змінюються.

Для збирання потрібні JDK 21+ (з `jpackage`) і Maven; тести під час встановлення не запускаються.

## Де зберігаються дані

Усе лежить у `~/.medicine/`:

| Шлях | Що це |
|---|---|
| `medicine.db` | база даних SQLite |
| `settings.properties` | налаштування: тема, вид панелі, масштаб шкали часу |
| `client_secret.json` | OAuth-клієнт Google (див. нижче) |
| `tokens/<id особи>/` | токен доступу Google для кожної особи |
| `logs/app.log` | журнал роботи |

## Налаштування Google Календаря

Без цього кроку застосунок повністю працює, лише без синхронізації.

1. Відкрийте [Google Cloud Console](https://console.cloud.google.com/) і створіть проєкт (наприклад, «Medicine»).
2. **APIs & Services → Library** → знайдіть **Google Calendar API** → **Enable**.
3. **APIs & Services → OAuth consent screen**:
   - тип користувачів **External**;
   - назва застосунку та ваш e-mail;
   - у розділі **Test users** додайте Google-акаунт кожного члена родини, який синхронізуватиметься.
4. **APIs & Services → Credentials → Create credentials → OAuth client ID**, тип **Desktop app**.
5. Завантажте JSON і збережіть його як `~/.medicine/client_secret.json`.
   > Поки застосунок у статусі **Testing**, Google анулює доступ до календаря приблизно через 7 днів —
   > тоді на вкладці особи з’явиться «G ⚠ Перепідключити». Щоб цього уникнути, на сторінці
   > **OAuth consent screen** натисніть **Publish app** (статус «In production»; перевірка Google для
   > особистого використання не потрібна — під час входу лише з’явиться попередження «неперевірений застосунок»).
6. Перезапустіть застосунок, відкрийте вкладку особи й натисніть **«Підключити Google»** — відкриється браузер для входу саме в акаунт цієї особи.

Після підключення в акаунті з’явиться окремий календар **«Ліки»** з подіями «💊 Назва — дозування» на найближчі 14 днів.
Коли дозу позначено як прийняту, подія стає «✅ …» і зеленою. Видалення ліків прибирає їхні майбутні події.
«Відключити Google» забуває токен; події, що вже є в календарі, залишаються (календар «Ліки» можна видалити вручну).
